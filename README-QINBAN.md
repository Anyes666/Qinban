# 琴伴使用指南 · 0.4.2

本指南对应琴伴桌面界面，帮助你完成 **选谱 → 试听 → 调校 → 授权演奏**。历史曲库扩充日志已移到 `docs/history/README-QINBAN-20261008.md`，不再混在操作说明中。

## 1. 启动与保存数据

已有运行包：完整解压到自己有写入权限的目录，双击 `QinBan.exe`，或使用同目录的 `Start-QinBan.cmd`。不要只搬走 EXE；曲库、许可文件与个人数据需要一并保留。

只有源码：按 `docs/DEVELOPMENT.md` 构建。本仓库目前没有发布可下载的琴伴运行包，不附带截图中的本地完整曲库。

默认个人数据在程序旁的 `UserData`，包含导入谱子、收藏、队列、逐曲设置和背景副本。源码运行时数据位于构建输出程序旁，并不是源码根目录。升级或迁移前退出程序，备份整个旧运行目录或至少 `UserData` 和 `Songs`；不要用空数据覆盖旧数据。

需要单独的数据目录时，可以明确指定：

```powershell
.\QinBan.exe --data-dir "D:\QinBanData"
```

## 2. 曲库：找到并选中一份谱子

- 左侧“曲库”进入谱目列表；搜索框支持曲名、歌手、语种、专辑、版本等信息。
- 本机完整曲库默认推荐“中文大众主力”；它是编辑分组，不是实时平台榜单。看不到目标曲目时，切换“全部曲库”并清空搜索。
- “筛选 / 歌单”展开更多管理入口；上一页、下一页切换当前结果。
- 点选曲目后，右侧显示歌曲信息、时长、音符数量、轨道和准备状态。
- “收藏”保存常用曲目；“加入队列”组织试听顺序。队列自动播放针对本地试听，不会自动在游戏中开始下一首。

全新源码构建的教学库没有完整中文流行分类。若推荐筛选为空，选择“全部曲库”，或先导入自己的合法谱子。

## 3. 导入自己的谱子

右上角“导入谱子”选择文件，或将谱文件拖进曲库。点击“文件夹”批量导入该文件夹的当前层文件，**不递归子目录，每批最多 200 个文件**。

| 格式 | 说明 |
| --- | --- |
| `.mid` / `.midi` | 标准 MIDI，读取音符时序与轨道 |
| `.txt` | 琴伴支持的键位文本谱或数字简谱 |
| `.json` | 琴伴谱结构或程序明确支持的键位 JSON；不是任意 JSON 都能导入 |

单文件最大 16 MiB、每谱最多 100,000 音符、时长不超过 30 分钟。超限或格式错误会提示；原始文件保留。PDF、图片、音频、MusicXML 不能直接作为可演奏谱导入，需要另外转换和核验。

### 工坊里的第一份练习谱

点击“谱子工坊”→“新建文本谱”，可以编辑数字简谱或键位谱。例如：

```text
TITLE=我的第一份练习谱
AUTHOR=我
BPM=100
FORMAT=numbered

1 2 3 4 5 6 7 1':2
(135):2 0 1:2
```

数字 `1`–`7` 表示音级，`'` 升高八度，`,` 降低八度，`0` 为休止；`:2` 表示两拍，括号表示同时发声。先“校验并试听”，确认无误后“另存到我的曲库”，程序创建副本，不覆盖来源谱。键位文本可使用 `FORMAT=keys`，例如 `A S D (ADG):2`。

## 4. 先试听，再调整

在歌曲下方选择乐器，与游戏中打开的乐器保持一致。点击“本地试听”，使用底部暂停、停止、进度条和试听音量控制。

本地试听是电脑合成预览，不向游戏发送按键，也不是游戏原声采样。时间轴与键位预览用来检查映射后的音符、节奏和可用键位；不能证明原谱一定准确。

点击“演奏调校”展开参数：

- **播放速度 / BPM**：改变演奏节奏。
- **移调 / 八度偏移**：适配乐器音域；结合映射说明检查折叠或跳过的音符。
- **和弦方式**：同时按下、琶音或旋律优先等处理，按歌曲需要选择。
- **MIDI 轨道 / 打击乐**：选择合适的旋律或伴奏轨道，按需排除打击乐。
- **循环范围**：对选定时间段练习。

参数按曲目保存。`Esc` 收起调校抽屉。改变谱子或演奏参数后，等界面“已准备”再继续操作；不会排队自动开始游戏演奏。

## 5. 向游戏演奏：必须主动授权

1. 启动原神，在游戏内打开目标乐器，关闭聊天与菜单。
2. 在琴伴选好谱子及同一种乐器，先完成试听和调校。
3. 打开“安全设置”，刷新并选择自己的原神窗口，阅读并勾选本次会话风险确认。
4. 点击底部“启用快捷演奏”，核对弹窗中的目标、谱子与乐器后确认。
5. 回到选定的原神前台窗口。按 **Shift+Enter**，松开两键即开始，**没有倒计时**。
6. **F8** 暂停 / 继续，**F9** 停止；“关闭快捷演奏”取消本次授权。

F9 或启动热键注册失败、目标窗口无效、谱子未准备好、所选乐器尚不可自动演奏时，程序会拒绝开始。切换离开目标游戏窗口会中断演奏并请求释放按键。合成压力测试谱禁止向真实游戏输出。

程序不能识别游戏内部的聊天框、背包或菜单状态。普通键位和快捷键会影响游戏，请自行遵守适用规则；本项目不保证账号安全，也不提供后台输入绕过、进程注入、内存读取或自动提权。

## 6. 外观与背景

点击左侧“外观背景”或右上“外观”。选择“纯净深色”可关闭背景图；本地图像仅复制到当前 `UserData/backgrounds`，不发送到网络。

可调整等比铺满 / 完整显示、暗化、模糊、面板实度和主体位置。图片导入支持 PNG / JPG / JPEG / BMP，最大 20 MiB；失败时保留当前背景，恢复默认也不会删除已导入副本。更多细节见 `APPEARANCE.md`。

## 7. 常见问题

| 问题 | 先检查 |
| --- | --- |
| 启动后曲库为空 | 源码仓库不附带完整曲库；切换“全部曲库”，在工坊新建或导入谱子 |
| 导入失败 | 文件扩展名、谱结构、体积、音符数量和时长；PDF / 音频不能直接导入 |
| 无法启用游戏演奏 | 目标窗口、本次授权、热键注册、准备状态及乐器是否可演奏 |
| Shift+Enter 没有开始 | 目标须在前台，两键须松开，Ctrl / Alt / Win 须松开；查看状态栏原因 |
| 乐器音高或和弦不合适 | 选择正确乐器、轨道、移调与和弦方式，检查映射说明，重新试听 |
| 不慎进入聊天框 | 先按 F9 停止，再关闭聊天；程序不能自动识别聊天状态 |
| 换电脑后收藏丢失 | 是否遗漏 `UserData`；先备份，勿直接覆盖新旧数据 |

反馈时提供版本、Windows 版本、操作步骤、错误原文和去除隐私的截图。不要公开整个 `UserData`、凭据或无再分发权的商业谱文件。
